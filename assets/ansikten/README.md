# Äventyrare-ansikten

Bilderna som visas i kategorin Äventyrare, där den som ritar huvudet ser ett ansikte i fem sekunder.

## Så lägger du till ett ansikte

1. Lägg bilden i den här mappen, till exempel `joel.jpg`. Kvadratiska bilder blir bäst, gärna runt 600 × 600 pixlar.
2. Lägg till personen i `ansikten.json`:

```json
[
  { "namn": "Joel", "fil": "joel.jpg" },
  { "namn": "Anna", "fil": "anna.jpg" }
]
```

`namn` är förnamnet som visas i spelet och i gubbens namn, till exempel "Joel som häst". `fil` är filnamnet på bilden i den här mappen.

## Tänk på

- **Repot är publikt.** Allt som läggs här syns för alla på GitHub, och finns kvar i historiken även om det tas bort senare.
- **Fråga kollegorna innan** deras ansikten läggs upp.
